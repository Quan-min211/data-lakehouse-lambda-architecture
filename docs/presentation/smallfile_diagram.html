Quy trình hợp nhất tự động 3 công đoạn không làm gián đoạn luồng đọc/ghi (Zero Downtime Snapshot Isolation):

  • Bin-Packing Compaction: Gộp các file nhỏ thành chuẩn 128 MB.
  • Expire Old Snapshots: Hủy metadata snapshot cũ hơn 7 ngày.
  • Remove Orphan Files: Quét sạch file rác không người quản lý trên MinIO.
⚡ Điều phối: maintenance.py & Dagster Schedule

Bin-Packing Compaction

  strategy => 'binpack',
  options => map(
    'target-file-size-bytes', '134217728',
    'min-file-size-bytes', '67108864'
  )
)

Thao Tác 2
Hết Hạn Snapshot Cũ

Hủy bỏ metadata của các Snapshot lịch sử cũ hơn 7 ngày, giải phóng dung lượng đĩa cho MinIO mà vẫn giữ tối thiểu 3 Snapshot.

CALL iceberg_catalog.system.expire_snapshots(
  table => 'bronze.crypto_trades',
  older_than => TIMESTAMP '<cutoff_7_days>',
  retain_last => 3
)
