# Configs
Thư mục chứa cấu hình cho từng dịch vụ trong hệ thống.

| Thư mục | Dịch vụ | Mô tả |
|:---|:---|:---|
| `kafka/` | Apache Kafka | Broker config, topic definitions |
| `spark/` | Apache Spark | Spark session, cluster config |
| `iceberg/` | Apache Iceberg | Catalog config, table definitions |
| `clickhouse/` | ClickHouse | Server config, DDL schemas |
| `redis/` | Redis | Redis config |
| `dagster/` | Dagster | Workspace, repository config |
