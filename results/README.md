# Results

Thư mục chứa kết quả benchmark và visualization.

| Thư mục | Mô tả |
|:---|:---|
| `logs/` | Raw benchmark log files (CSV) |
| `plots/` | Biểu đồ kết quả (latency, compaction, correctness) |

> **Lưu ý:** Các file CSV lớn và ảnh biểu đồ được liệt kê trong `.gitignore`.
> Chỉ commit các template CSV nhỏ và biểu đồ tổng kết cuối cùng.
